This document contains an english text translation for the 3 special chapters of the Ubunchu manga created by Hiroshi Seo. To make use of this translation you will need to purchase the Japanese original contained inside the Ubunchu Tankōbon and put it side-by-side. The original is available for purchase on \href{https://bookwalker.jp/decf255320-459b-4d7c-92d3-8d5281052c28/}{BookWalker} and \href{https://www.amazon.co.jp/-/en/dp/B00N4M5S8K}{Amazon Japan}.\\

For more information on this translation as well as translations for other chapters click \href{https://github.com/publicdesert/ubunchu_english}{here}.
